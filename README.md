# EcoVision 🌱 — المساعد البيئي الذكي

تطبيق ويب تفاعلي (PWA) يستخدم نموذج تصنيف الصور من Edge Impulse للتعرف الفوري على نوع النفايات
(معدن، بلاستيك، ورق) عبر كاميرا الجهاز، ويقدّم إرشادات إعادة تدوير مباشرة بالعربية، بصوت ونص.

## التشغيل محلياً

يتطلب المتصفح اتصالاً آمناً (HTTPS) أو `localhost` للوصول إلى الكاميرا، لذا شغّل خادماً محلياً بسيطاً:

```
python3 server.py
```

ثم افتح `http://localhost:8082` في المتصفح (يُفضّل Chrome على الجوال لدعم أفضل لـ Web Speech API).

> لتجربة التطبيق كتطبيق مثبت (PWA) على الجوال، افتح الرابط عبر HTTPS حقيقي (مثلاً بعد رفعه على أي استضافة ثابتة)
> ثم اختر "إضافة إلى الشاشة الرئيسية" من قائمة المتصفح.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الواجهة والمنطق الكامل للتطبيق |
| `manifest.json` | بيانات تعريف PWA (اسم التطبيق، الأيقونة، الألوان) |
| `sw.js` | Service Worker لتفعيل العمل دون اتصال بعد أول تحميل |
| `icon.svg` | أيقونة التطبيق |
| `edge-impulse-standalone.js` / `.wasm` | نموذج التصنيف المُصدَّر من Edge Impulse (WebAssembly) |
| `server.py` | خادم HTTP بسيط للتجربة المحلية |

## أبرز المزايا

- **تحليل لحظي بالكامل داخل المتصفح**: لا حاجة لإرسال أي صورة إلى خادم خارجي.
- **واجهة زجاجية داكنة (Dark Glassmorphism)** بلمسة نيون خضراء مستوحاة من الطبيعة والتقنية.
- **مؤشر دقة وبطاقة إرشاد بيئي** فورية بعد كل عملية فحص، مع أثر بيئي تقديري لكل مادة.
- **عداد الأثر البيئي** لعدد العناصر المصنَّفة خلال الجلسة.
- **تغذية راجعة حسّية**: اهتزاز خفيف + مؤثر صوتي عند بدء الفحص (عبر Web Audio API، دون ملفات صوت خارجية).
- **إتاحة وسهولة وصول**:
  - نطق تلقائي للنتيجة والنصيحة بالعربية عبر `Web Speech API`، وزر لإعادة النطق يدوياً.
  - وضع تباين عالٍ (High Contrast) يمكن تفعيله من الزر العلوي.
  - رموز تعبيرية كبيرة وواضحة لكل نوع مادة، ولغة عربية مبسّطة.
  - زر فحص واحد كبير وواضح، ومنطقة نتائج بها `aria-live` لقارئات الشاشة، ودعم التنقل بلوحة المفاتيح.
  - احترام إعداد "تقليل الحركة" (`prefers-reduced-motion`) في المتصفح/النظام.
- **PWA**: قابل للتثبيت على الشاشة الرئيسية، ويعمل دون اتصال بعد أول تحميل بفضل الـ Service Worker.

## ملاحظات تقنية

- يتم اقتطاع كل إطار إلى 160×160 بكسل، ثم تحويله إلى صيغة RGB المعتمدة لدى Edge Impulse قبل تمريره
  إلى `classifier.classify()`.
- أيقونة التطبيق الحالية بصيغة SVG بسيطة لأغراض العرض؛ لتوزيع رسمي على متاجر التطبيقات يُنصح باستبدالها
  بأيقونات PNG بمقاسات متعددة (192×192، 512×512).
- أسماء الفئات المعروضة بالعربية (`ecoDatabase` في `index.html`) قابلة للتوسعة بسهولة لإضافة فئات جديدة
  حسب فئات النموذج المدرَّب فعلياً في مشروع Edge Impulse الخاص بك.
